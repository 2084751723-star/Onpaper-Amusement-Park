# 纸上游乐场 · 失落森林｜110 秒演示提纲

## 演示准备

- 本稿配图来自 2026-11-20 的本地真实浏览器操作，运行代码基线为 `0abf328ecefbaa2122d383a9180c1b0a74dbcd30`。本分支仅内联乙组件测试夹具并整理材料，没有改动运行逻辑。它不是公网验收记录。
- 在项目根目录执行 `npm run dev -- --host 127.0.0.1 --port 5181 --strictPort`。端口占用时换一个空闲端口，不结束未知进程；以下地址需同步换端口。
- 本地入口：[角色入口](http://127.0.0.1:5181/)；固定示范题：[A 地图](http://127.0.0.1:5181/?v=1&seed=000000&role=a)、[B 线索](http://127.0.0.1:5181/?v=1&seed=000000&role=b)。这些回环地址只用于本机，不要发给异地搭档。正式演示使用甲实际发布且乙验收过的站点生成的链接，不猜地址。
- A、B 分别打开自己的角色链接，核对题号均为 `1-000000`。开场前 A 点击“清空”，以免本端存档影响演示；不要点击“切换题目”。讲解者可切换窗口展示差异，正式玩家不要看对方页面。
- 预先打开下方真实 PDF。演示展示现有 PDF 的页数，不把网页中的两张卡片当成真实分页，不假装操作过系统打印对话框。

## 时间轴

目标总时长 110 秒，属于讲解节奏安排，不是已录制视频的计时结果；以下玩法操作已通过自动化真实浏览器复演，尚未进行真人口播计时。

| 时间 | 画面与操作 | 建议讲解 |
|---|---|---|
| 0—12 秒 | 展示角色入口与题号 | “这是一个两人合作的森林寻路谜题。两人拿到同一道题，但看见的信息不同。” |
| 12—25 秒 | 依次展示 A 地图、B 线索 | “A 只有地图和起点，B 只有按顺序排列的符号及方向限制。两人用现有通话交流，网页本身不提供语音或实时房间。” |
| 25—58 秒 | B 依次读六条线索；A 按下表走完六步 | “每步只能上下左右走一格，不能穿障碍，也不能重走。第五条还禁止向东。” |
| 58—70 秒 | A 点击“提交路径”，展示成功反馈 | “校验的是整条路径，不是只猜最后一个格子。” |
| 70—82 秒 | 刷新 A 页，展示保留的七个路径格 | “当前设备会保存这题的已选路径。刷新后路径还在，但不会伪造上一次的提交成功提示。” |
| 82—100 秒 | 打开打印预览，勾选并取消“附上本题答案”；切到事先打开的两页/三页 PDF | “默认分给两位玩家各一张 A4。答案是可选第三页，完成挑战后再看。黑白 PDF 已检查，实体打印还没有验收。” |
| 100—110 秒 | 展示真实 Qoder 过程截图，收束 | “开发中用 Qoder 分工实现和测试，通过 GitHub 交接。谜题由确定性规则生成，再由独立求解器验证，不是运行时让 AI 随机出题。” |

### 固定题操作表（仅供讲解者，不给玩家作提示）

起点为第 3 行、第 1 列；页面行列均从 1 开始。六步不包含起点，完成后共选中七格。

| 步 | B 的实际线索 | A 选择的格子 | 移动 |
|---|---|---|---|
| 起点 | 不对应线索 | 第 3 行，第 1 列 | 不移动 |
| 1 | 树叶 | 第 2 行，第 1 列 | 上 |
| 2 | 蘑菇 | 第 1 行，第 1 列 | 上 |
| 3 | 树叶 | 第 1 行，第 2 列 | 右 |
| 4 | 月亮 | 第 2 行，第 2 列 | 下 |
| 5 | 树叶，禁止向东（右） | 第 3 行，第 2 列 | 下 |
| 6 | 星星 | 第 4 行，第 2 列 | 下 |

成功反馈应为“验题通过：完整路径正确，宝藏已找到！”。若题号不同，回到固定 A/B 链接，不照搬这条路径到其他题。

## 异常处理与验证边界

- 复制失败时，页面选中完整只读链接并提示手动复制；不要口播“已发送”或虚构对方已加入。
- 点错可“撤销”；要重演用“清空”。非法跳格、重复格子、步数不足、符号不符的完整路径都有拒绝场景，未安排在主时间轴中逐一展开。
- 浏览器复演覆盖 320/390/1280px、原生键盘与触控事件、正确及错误路径、A/B 展示分离、刷新恢复、新题、非法 URL；这是自动化功能验证，不是两位真人异地试玩或趣味性调查。
- 乙-3 共导出检查 38 份 PDF、95 页：`000000`—`00000F` 覆盖两模板×八种几何变换，加 `ABCDEF` 符号置换样例，以及两个样例的背景开关与取消答案重导。不是 384 个变体的全量 PDF 验证。
- 未录制或生成视频，未发论坛帖；未验证实体打印、物理手机、其他浏览器或公网版本。本稿中的画面仅证明记录时的本地状态。
